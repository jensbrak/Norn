# Security Policy

## Supported versions

Security fixes are made against the current release of Norn. Older versions
are not maintained separately.

## Reporting a vulnerability

If you believe you have found a security vulnerability in Norn, please do not
open a public GitHub issue with exploit details.

Use GitHub's private vulnerability reporting feature for this repository
instead.

Please include enough information to reproduce the problem, including the
Norn version, operating system, and relevant input or steps where practical.

This is a hobby project with no guaranteed response time, but security reports
will be reviewed as soon as practical.

Ordinary bugs, malformed-save handling issues, crashes, and feature requests
that do not have security implications should be reported through the normal
GitHub issue tracker.
