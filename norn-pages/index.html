Open-source Valheim character editor

Norn

Inspect and edit local Valheim character saves on Windows and Linux.

Norn edits a deliberate, tested subset of .fch character data while preserving everything it does not yet understand byte-for-byte.

Before you use it

Back up first.
Norn writes a .fch.old backup when saving, but that is a convenience rather than a backup strategy.

Local saves only.
Norn reads Valheim's local character directories and deliberately does not modify Steam Cloud saves.

Unofficial project.
Norn is an independent hobby project and is not affiliated with Iron Gate AB or Coffee Stain Publishing.

What it does

Character data without pretending the format is simpler than it is

Identity & appearance

Edit character identity and appearance fields with explicit round-trip support.

Inventory & progression

Work with inventory, skills, food and health data through a desktop UI.

Per-world exploration

Inspect character-specific world map exploration and placed pins.
